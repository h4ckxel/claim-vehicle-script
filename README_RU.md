## `> ЧТО ЭТО?`

Lua-скрипт для **YimMenu** и **NewWay Menu**, позволяющий сохранить **любой транспорт**, в котором находится игрок, как **личный транспорт (PV)** — без покупки в игровом магазине.

> Принцип работы: скрипт напрямую вызывает внутренние функции скрипта GTA Online `am_mp_vehicle_reward`, воспроизводя поток, который игра использует при выдаче транспорта в качестве награды.

## `> СОВМЕСТИМОСТЬ`

```
[✓] YimMenu   — необходимо включить поддержку Lua-скриптов
[✓] NewWay Menu — необходимо включить поддержку Lua-скриптов
[✗] Другие меню не гарантированы (зависит от реализации scr_function / locals API)
```

---

## `> ТРЕБОВАНИЯ`

```
[✓] Активная сессия GTA Online
[✓] Скрипт "freemode" запущен
[✓] Скрипт "am_mp_vehicle_reward" запущен
[✓] Игрок должен находиться в транспортном средстве
[✗] Заблокированный транспорт (blacklist) НЕ работает
     → игра всё равно удаляет его после отключения патчей
```

---

## `> УСТАНОВКА`

```bash
# 1. Скопируй .lua файл в папку скриптов своего меню:
#    YimMenu  → %APPDATA%\YimMenu\scripts\
#    NewWay   → папка scripts\ в директории установки

# 2. Запусти GTA Online

# 3. Сядь в любое транспортное средство

# 4. В меню перейди:
#    Вкладка Транспорт → "Claim Current Vehicle as PV"

# 5. Выбери гараж и слот, когда игра запросит

# 6. Готово. Транспорт сохранён как личный.
```

## `> ТЕХНИЧЕСКИЕ ДЕТАЛИ`

| Переменная | Значение | Описание |
|---|---|---|
| `GARAGE_MENU_DATA` | `176` | Смещение меню гаража в локальных переменных |
| `VEHICLE_REWARD_DATA` | `129` | Базовое смещение блока данных награды |
| `+4` | transaction | Результат транзакции |
| `+5` | garage_id | ID целевого гаража |
| `+6` | garage_slot | Слот внутри гаража |
| `+7` | reward_state | Состояние процесса (`3` = ожидание) |

---

## `> ОГРАНИЧЕНИЯ`

```
[-] Заблокированный (blacklist) транспорт отклоняется игровым движком
[-] Скрипт "am_mp_vehicle_reward" должен быть активен
[-] Только онлайн-режим (в режиме истории не работает)
[-] Игрок обязан находиться за рулём транспорта
```
